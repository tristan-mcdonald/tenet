Tenet CSS

This is the reference page for the framework. Resize the browser window and watch the type, spacing, and element sizes interpolate fluidly between the small and large viewport definitions — no font-size media queries required.

The typographic scale

Headings step up through a modular scale whose ratio itself interpolates with the viewport. The paragraph you are reading is constrained to a comfortable measure by the reading_content wrapper.

A third-level heading

Body copy sits at the base font-size. Inline styling is handled by the framework too: strong text uses a heavier weight of the same variable font, emphasised text uses its italic style, and footnotes can be marked with a superscript1 or subscript2.

A fourth-level heading

Links inside reading content are styled distinctly, for example this anchor within a paragraph. Try tabbing through the page with your keyboard to see the accessibility-aware focus styles, which only appear for keyboard users. Description lists

A description list without a class displays each term beside its description. Wrap each pair in a div.

Typeface
Inter for body text, and Fraunces for headings.
Format
Variable WOFF2 files, with a single file per style.
Fallback
Metric-matched system fonts, to minimise layout shift.

Forms

Text fields use a floating label, which rests inside the field until it has focus or a value. Validation styles appear only once you've interacted with a field.

Dialogs

Dialogs use the native dialog element, opened and closed by buttons with command and commandfor attributes. Close them with the close button, the escape key, or by clicking the backdrop.

An example dialog

The dialog grows into view as it opens, over a backdrop which fades in behind it. Focus moves into the dialog, and the page behind it can't be scrolled or interacted with until the dialog closes.
